# V0: LangChain exploration

These are the first experiments, run against local Ollama models before switching to vLLM.

| File | Contents |
|---|---|
| `V00test.ipynb` | A smoke test of LangChain with Ollama |
| `V01Baseline.ipynb` | First baseline, versions 0.1.x, ending with LangChain's `SQLDatabaseToolkit` |
| `V02ModelTesting.ipynb` | The same agent with models of different sizes |
| `V03LangGraphCustomTools.ipynb` | First custom tools in LangGraph |
| `SQLite.ipynb` | Test queries against the SQLite BIRD databases |
| `eval/` | Early evaluation scripts written before switching to BIRD's own evaluation |
| `prompts/` | Early SQL-generation and toolkit prompts |
